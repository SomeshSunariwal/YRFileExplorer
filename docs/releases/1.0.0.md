# YR File Explorer — v1.0.0 Release Notes

**Version:** 1.0.0 · **Build:** 1 · **Requires:** Android 12 or newer

The first release combines file management, storage analysis, archives, built-in viewers, and user-configured network connections in a tabbed workspace.

## File management

- Browse Device storage, SD cards, USB drives, and supported document-provider locations. External storage displays its volume name.
- Create, rename, copy, cut, move, share, hide, and delete files and folders.
- Search files and folders, use deeper search, and access Download and Recent shortcuts.
- Inspect properties and calculate file checksums.
- Save favorite folders on the homepage; Favorites appears when it contains an item.
- Restore deleted items from the Recycle Bin or empty the bin explicitly.

## Views and selection

- Grid, List, and Details views with Small, Medium, and Large item sizes.
- Sorting by name, type, size, or modified time, with ascending/descending ordering.
- Optional grouping by Name, Size, or Type, using lined, collapsible headings and a separate ordering control. None restores the flat view.
- Folders before files, including hidden items, after sorting and grouping.
- Hidden files and folders displayed at reduced opacity.
- Image thumbnails preserve their proportions inside square icon areas.
- Corner checkboxes, multiple selection, and swipe selection/deselection.
- Ghosted drag previews for selected files and folders, with a one-second hold before moving an existing selection.

## Tabs and split view

- Workspace tabs for folders, categories, tools, archives, and network pages.
- Top tab navigation, horizontal page transitions, breadcrumbs, and history.
- Window previews, close controls, startup-window selection, New, and Close others.
- A Clipboard section for copied or cut items.
- A nested New window dialog that keeps the Windows panel underneath.
- Resizable top/bottom split view with independent folder navigation and a shared action bar that follows the active pane.
- Copy, move, and drag items between panes. Page swipes are disabled during split view; the upper close control remains disabled until the lower pane is closed.

## Storage Analyzer

- Recursive folder sizes, file/folder counts, category totals, and proportional storage usage.
- A red/green capacity bar showing used and available storage.
- Dedicated result tabs for large files, recently modified files, empty folders, and duplicates.
- SHA-256 duplicate verification and expandable groups with individual-copy selection.
- A separate cancellable scan dialog showing the current file and progress totals.
- Copyable analysis reports.
- An optional Show folder sizes setting for calculations during ordinary browsing.

## Archives and protection

- Built-in ZIP and 7z browsing, creation, and extraction.
- Optional archive passwords and header-based navigation through archive folders.
- Extraction into a new destination, with unsafe archive paths rejected.
- Password-based encryption and decryption for individual files.

## Music player

- Local playback with artwork, title/artist information, a seek bar, and elapsed/total time.
- Previous/next, shuffle, repeat-all, and repeat-one controls, including a visible “1” for repeat-one.
- Playing and Playlist pages with a swipe-linked top switcher.
- Track selection and locally saved playlists.
- Recognition of common Android audio formats: MP3, AAC, M4A/M4B, FLAC, WAV, OGG/Opus, AMR, and MIDI.
- Optional Background playback in Settings. When disabled, leaving the player stops playback.

## Images, video, PDF, and text

- Image viewing with zoom, rotation, sharing, deletion, and a scrolling thumbnail strip.
- Local video playback on a black background.
- Offline PDF reading with continuous scrolling, zoom, page navigation, and a page-jump dialog.
- Text editing with encoding, line-ending, and font-size controls.

## Applications

- App artwork for readable APK files in the browser.
- Installed-app browsing, search, selection, launch, sharing, and backup/export.
- Android-managed APK installation and app uninstallation flows.

## Network and downloads

- FTP, FTPS, SFTP, SMB/LAN, and WebDAV connection profiles.
- Remote browsing, upload/download, folder creation, rename, copy/move, and deletion where supported by the server and protocol.
- User-triggered LAN discovery, SFTP host-key verification, and optional Android-Keystore password storage.
- HTTP/HTTPS web tabs and Download Manager with progress, cancellation, retry, opening completed files, and history removal.
- Bluetooth discovery, pairing controls, sharing, and OBEX browsing when supported by the other device.

## Appearance and privacy

- Cyan accents, light surfaces, a `#292929` dark theme, rounded controls, and floating action bars.
- Eight homepage category shortcuts in two rows of four, storage volumes, Tools, Network, and Favorites when populated.
- Shared search, selection, and progress-dialog styles.
- Saved preferences retained across app updates.
- No advertising, tracking, or analytics SDKs. Local file management requires no backend server; network features run when requested by the user.

## Compatibility notes

- All files access is required on first launch. Android manages it under Special app access, separately from ordinary app permissions.
- APK installation and Bluetooth use their respective system permissions.
- Android's protected app directories remain restricted even with all-files access.
- Analysis includes hidden files and skips unreadable paths and symbolic links. Provider results depend on available permissions and metadata.
- Audio/video decoding depends on the device and the codec inside the file.
- Network implementations are included; complete end-to-end interoperability validation remains pending. Bluetooth transfers require a compatible peer.
- Google Drive, other cloud-account integrations, and Remote Manager are not included in v1.0.0.
