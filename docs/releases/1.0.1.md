# YR File Explorer 1.0.1

**Android version code 2** · **Android 12 or newer**

## Private Space and nearby sharing

- Added encrypted **Private Space**, unlocked with the device’s screen lock or fingerprint. Move selected files and folders into it from the current tab, then manage them or move them back out from the Private Space tab. [Private Space security and recovery](../private-space.md)
- Added **Sharing** for nearby transfers over Wi-Fi Direct. Create or join a network, pair with a six-digit code, and send selected files or folders from the action menu. Nearby discovery stops after two minutes.
- **Sharing History** shows per-file transfer progress and status. Tap a completed file to open it while it is still available at its saved location.
- Received transfers default to the phone’s **Download** folder, with a subfolder for each transfer batch. Set a different destination under **Settings → Files & sharing → Received files location**.
- The **New download** dialog now uses the folder picker. It starts in **Download** and shows the chosen destination in the form.

## Music, video, images, and PDFs

- The music player now has a taller, multicolored visualizer with bars that react in place. The compact volume slider follows Android media volume, including changes from the phone’s volume buttons.
- Back and the three-dot menu flank the swipe-linked **Playing** and **Playlist** tabs in one row. Active Shuffle and Repeat icons turn cyan, Shuffle shows a slash when off, and tapping the currently playing track in the playlist keeps its playback position.
- The video player has translucent controls, ten-second skips, and a display menu with **Full Screen**, **Stretch**, and **Fit**. The image viewer uses matching translucent controls and fits images to the available space while preserving their proportions.
- The PDF viewer has pinch-to-zoom centered under the gesture, a compact page-count button for jumping to a page, and a three-dot menu with **Find in page**, **Share**, and **Print**. Text search requires a PDF text layer and Android 15 or newer, or Android 12 SDK extension 13 or newer.

## Browsing, tabs, and storage analysis

- File search updates after three characters and shows matching folders before files. Supported files open through the same viewer flow from the file browser, archive previews, Storage Analyzer results, and Sharing History.
- Hold an unselected item for half a second, then slide to select more. Ordinary swipes still scroll with a selection active. Holding a selected local item gathers the selected files and folders into a translucent drag preview.
- Device is available by swipe as soon as the workspace opens. The main Device header’s close button is disabled, and the lower split pane can be closed independently. FTP supports a split view with Device, and one toolbar follows the focused pane.
- Storage Analyzer shows the current folder in its header and supports hold-and-slide selection. **Locate** opens the containing folder of a selected duplicate. Archive charset selection now marks the active option.
- The homepage has more compact Tools and Network cards. Other refinements include visible scroll indicators, aligned selection controls, updated window previews, and compact notifications that animate above the toolbar without shifting content. Redundant file-row menus and the `file (Local)` option were removed.
- File list metadata shows the size, abbreviated month, and 12-hour time. It omits the year for files dated in the current year.

## Compatibility

- Nearby sharing requires two compatible Android devices with Wi-Fi Direct and the required permissions.
- Media playback depends on the codecs available on the device.
