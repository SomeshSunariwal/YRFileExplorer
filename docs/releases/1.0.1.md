# YR File Explorer 1.0.1

Android version code: **2**. Supports Android 12 and newer.

- Added encrypted Private Space, protected by the device's fingerprint or screen
  lock. Move selected files and folders into the vault without leaving the current
  page; copy, rename, organize, delete, or move them back out from its own tab.
- Standardized selection: hold an unselected item for half a second, then slide
  to select more. Repeat on another unselected item to extend the selection.
  Ordinary swipes scroll without clearing it. Hold a selected local item to drag
  the selected files/folders. The hold duration is defined centrally.
- Added visible scroll-position indicators to overflowing vertical views.
- Enabled FTP split views with an adjustable Device pane and one toolbar that
  follows the focused pane. Supported New window types display a split indicator.
- Added consistent rounded notifications with a half-second fade-up entrance and
  fade-out dismissal, without shifting page content.
- Improved window-preview shadows and theme-aware button outlines, fixed selected
  list-row alignment, and removed redundant row menus and the file (Local) option.
- Made Device available for swiping immediately after startup. Its primary-pane
  close button stays disabled; the lower split pane remains closable.
- Storage Analyzer now displays the current folder in its header while keeping
  its root title, and supports the shared hold-and-slide selection behavior.
- List metadata now includes size, abbreviated month, and 12-hour time, omitting
  the year when it is the current year.

See [Private Space security and recovery details](../private-space.md). No cloud,
advertising, or tracking features were added.
